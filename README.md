A Python 3 standard-library-only program that draws a newspaper-style poster summing up the world news of Tuesday 17 November 2026 in a single 1024x1024 PNG: a date banner plus six story rows (US-Iran strikes at Hormuz, the Crimea Bridge hit again, the Quad summit in Manila, the US losing its measles elimination status, jets scrambled over Japan, and COP31 in Antalya). Every story was verified against at least two independent news sources dated 17 November 2026 before the image was drawn. The program uses no network, no fonts and no third-party packages: text is rendered with a built-in 5x7 bitmap font and the PNG is encoded by hand, so two runs produce byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
